# CROWD GHOST

Every crowd leaves a ghost. Fix it.

A haunted museum rendered as ASCII. A crowd flows through rooms; queues show up as visual "pressure". You reshape the building (doors, walls, entry spacing) while an AI "Curator" narrates and recommends fixes. Under the art: a real queueing-network model, validated against simulation.

Status: under construction, stage by stage. See `PLAN.md` and `STAGE_*.md` notes.
